# NovelAI Image SDK (Kotlin/JVM)

Kotlin bindings for [`novelai-image-sdk`](https://github.com/xinvxueyuan/NovelAI-Image-SDK),
generated by UniFFI over the Rust core.

```kotlin
import io.github.xinvxueyuan.novelai.image.sdk.Credentials
import io.github.xinvxueyuan.novelai.image.sdk.GenerationRequest
import io.github.xinvxueyuan.novelai.image.sdk.NativeLoader
import io.github.xinvxueyuan.novelai.image.sdk.NovelAiClient

NativeLoader.load() // extracts the bundled native library and sets jna.library.path

val client = NovelAiClient(
    Credentials(token = System.getenv("NOVELAI_TOKEN"), username = null, password = null),
    null,
)
val request = GenerationRequest(
    prompt = "1girl, smile",
    width = 832u,
    height = 1216u,
    // every other field is optional (null)
    baseCaption = null, model = null, action = null, negativePrompt = null,
    nSamples = null, steps = null, scale = null, sampler = null, seed = null,
    extraNoiseSeed = null, noiseSchedule = null, quality = null, ucPreset = null,
    cfgRescale = null, image = null, mask = null, strength = null, noise = null,
    references = null, referenceInformation = null, estimateOnly = null,
)

val resolved = client.resolveRequest(request)
println("${resolved.width} ${resolved.payloadJson}")
println(client.estimateAnlasCost(request, false).anlas)

// `generate` is a suspend function: call it from a coroutine.
```

`generate`, `collectGeneration`, `upscale`, `annotate`, `director`,
`encodeVibe`, `suggestTags` and the account reads are `suspend` functions, so
they compose with `kotlinx.coroutines` without blocking a thread.

## Native library

The JAR carries `resources/<os>-<arch>/libnovelai_image_sdk_ffi.{dll,so,dylib}`
and `NativeLoader` extracts it to a temporary directory. Set
`NOVELAI_SDK_AUTOLOAD=0` to disable the automatic call and invoke
`NativeLoader.load()` yourself.

## Transport

Requests carry Chrome's TLS (JA3/JA4) and HTTP/2 fingerprint plus the matching
header block, because `image.novelai.net` sits behind Cloudflare and resets
connections that do not look like a browser.
