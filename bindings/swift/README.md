# NovelAI Image SDK (Swift)

Swift bindings for [`novelai-image-sdk`](https://github.com/xinvxueyuan/NovelAI-Image-SDK),
generated by UniFFI over the Rust core.

```swift
import NovelAIImageSDK

let client = try NovelAiClient(
    credentials: Credentials(token: ProcessInfo.processInfo.environment["NOVELAI_TOKEN"],
                             username: nil, password: nil),
    options: nil
)

let request = GenerationRequest(
    prompt: "1girl, smile",
    width: 832, height: 1216
    // remaining fields default to nil
)

let resolved = try client.resolveRequest(request: request)
print(resolved.width, resolved.payloadJson)
print(try client.estimateAnlasCost(request: request, opus: false).anlas)

let images = try await client.generate(request: request)
for image in images {
    try image.data.write(to: URL(fileURLWithPath: image.filename))
}
```

Async methods surface as Swift `async`/`await`, so they compose with structured
concurrency and cancellation.

## Installation

The package is distributed through Swift Package Manager; the Rust static
library ships as an XCFramework in the GitHub release this package points at.
Building from source requires running `cargo xtask bindings --language swift`
and `cargo build -p novelai-image-ffi-uniffi --release` first.

## Transport

Requests carry Chrome's TLS (JA3/JA4) and HTTP/2 fingerprint plus the matching
header block, because `image.novelai.net` sits behind Cloudflare and resets
connections that do not look like a browser.
